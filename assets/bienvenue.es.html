Bienvenido a Sanaga

Sanaga es un navegador rápido y sobrio. Muestra los sitios con WebKit, un motor web maduro (el de Safari y GNOME Web): diseño completo, JavaScript, vídeos y aplicaciones web funcionan.

¿Necesitas ahorrar todavía más? En Ajustes, elige el motor Sanaga Ligero: muestra lo esencial de las páginas —textos, títulos, enlaces, imágenes y formularios— sin JavaScript ni anuncios, con muy poca memoria.

Lo que Sanaga sabe hacer

  • Pestañas: cada pestaña solo arranca su motor cuando muestra un sitio.
  • Barra de direcciones inteligente: escribe una dirección o una búsqueda, Sanaga lo entiende.
  • Lector: el botón con forma de página en la barra de direcciones muestra solo el artículo, sin menús ni anuncios, con texto grande y tres temas (blanco, sepia, noche).
  • Lista de lectura: guarda una página para más tarde (menú ⋮ o Ctrl + Mayús + D); aparece en la barra lateral y en la página de inicio.
  • Vista general de pestañas (botón de cuatro cuadrados o Ctrl + Mayús + O): todas tus pestañas en miniatura.
  • Grupos de pestañas en la barra lateral (Ctrl + Mayús + L), pestañas fijadas, pestañas que puedes mover arrastrándolas, clic derecho para duplicar, silenciar o cerrar las demás.
  • Compartir (botón cuadrado con una flecha): copiar el enlace, enviar por correo, imprimir, crear una aplicación web que se abre sola desde el menú de aplicaciones.
  • Protección contra el rastreo entre sitios e Informe de privacidad en la página de inicio.
  • Traducir la página, pantalla completa (F11), código fuente (Ctrl + U), Inspector web (Ctrl + Alt + I), zoom recordado por sitio.
  • Contraseñas: Sanaga ofrece guardarlas en el llavero de tu sistema y rellenarlas la próxima vez; autorrelleno de tus datos (Ctrl + Mayús + F).
  • Perfiles (Personal, Trabajo…): cada uno con sus favoritos, historial, contraseñas y cookies, en su propia ventana.
  • Extensiones: bloqueador de anuncios, sin reproducción automática, modo oscuro para todos los sitios y tus propios scripts.
  • Sincronización mediante una carpeta compartida: favoritos, lista de lectura y pestañas de tus otros dispositivos.
  • Ahorro de memoria: las pestañas sin usar se suspenden y se recargan al volver.
  • Barra de direcciones: ir a una pestaña ya abierta, atajos de búsqueda (w Wikipedia, yt YouTube, m mapa, tr traducción…) y calculadora (escribe 12*3).
  • Buscar en las pestañas (Ctrl + Mayús + A), guardar la página (Ctrl + S), código QR de la página en Compartir.
  • Permisos de los sitios (cámara, micrófono, ubicación, notificaciones) y borrado de datos de navegación (Ctrl + Mayús + Supr).
  • Importar tus favoritos desde Chrome, Chromium, Brave, Edge, Vivaldi o un archivo HTML.
  • Multilingüe: français, English, español, português, Deutsch (Ajustes › Idioma).
  • Favoritos e historial, guardados en tu ordenador.
  • Navegación privada: no se guarda nada, las cookies se mantienen aparte.
  • Dos motores: WebKit para sitios completos, Sanaga Ligero para leer rápido con muy poca memoria.
  • Descargas en tu carpeta Descargas.
  • Buscar en la página y zoom.

Bueno saber

El motor WebKit muestra los sitios como un navegador clásico. El motor Sanaga Ligero no ejecuta JavaScript: el correo web, los vídeos y las aplicaciones web quedan incompletos, pero los sitios de noticias, enciclopedias y blogs se leen muy bien.

Para empezar, prueba Wikipedia, Hacker News o NPR en versión texto.
