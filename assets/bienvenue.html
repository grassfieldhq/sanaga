Bienvenue dans Sanaga

Sanaga est un navigateur rapide et sobre. Il affiche les sites avec WebKit, un moteur web mature (celui de Safari et de GNOME Web) : mise en page complète, JavaScript, vidéos et applications en ligne fonctionnent.

Besoin d'économiser encore plus ? Dans les Paramètres, choisissez le moteur Sanaga Léger : il affiche l'essentiel des pages — textes, titres, liens, images et formulaires — sans JavaScript ni publicités, avec très peu de mémoire.

Ce que Sanaga sait faire

  • Onglets : chaque onglet ne démarre son moteur que lorsqu'il affiche un site.
  • Barre d'adresse intelligente : tapez une adresse ou une recherche, Sanaga comprend.
  • Lecteur : le bouton en forme de page dans la barre d'adresse affiche l'article seul, sans menus ni publicités, avec le texte en grand et trois thèmes (blanc, sépia, nuit).
  • Liste de lecture : gardez une page pour plus tard (menu à trois points ou Ctrl + Maj + D) ; elle apparaît dans la barre latérale et sur la page d'accueil.
  • Aperçu des onglets (bouton à quatre carrés ou Ctrl + Maj + O) : tous vos onglets en vignettes.
  • Groupes d'onglets dans la barre latérale (Ctrl + Maj + L), onglets épinglés, onglets à déplacer en les faisant glisser, clic droit pour dupliquer, couper le son ou fermer les autres.
  • Partager (bouton carré avec une flèche) : copier le lien, envoyer par e-mail, imprimer, créer une application web qui s'ouvre seule depuis le menu des applications.
  • Protection contre le suivi intersites et Rapport de confidentialité sur la page d'accueil.
  • Traduire la page, plein écran (F11), code source (Ctrl + U), Inspecteur web (Ctrl + Alt + I), zoom mémorisé par site.
  • Mots de passe : Sanaga propose de les enregistrer dans le trousseau de votre système et de les remplir à la visite suivante ; remplissage automatique de vos coordonnées (Ctrl + Maj + F).
  • Profils (Personnel, Travail…) : chacun avec ses favoris, son historique, ses mots de passe et ses cookies, dans sa propre fenêtre.
  • Extensions : bloqueur de publicités, pas de lecture automatique, mode sombre pour tous les sites, et vos propres scripts.
  • Synchronisation par un dossier partagé : favoris, liste de lecture et onglets de vos autres appareils.
  • Économiseur de mémoire : les onglets inutilisés se mettent en veille et se rechargent quand vous y revenez.
  • Barre d'adresse : passer à un onglet déjà ouvert, raccourcis de recherche (w Wikipédia, yt YouTube, m carte, tr traduction…) et calculatrice (tapez 12*3).
  • Rechercher dans les onglets (Ctrl + Maj + A), enregistrer la page (Ctrl + S), code QR de la page dans Partager.
  • Autorisations des sites (caméra, micro, position, notifications) et effacement des données de navigation (Ctrl + Maj + Suppr).
  • Importer vos favoris depuis Chrome, Chromium, Brave, Edge, Vivaldi ou un fichier HTML.
  • Multilingue : français, English, español, português, Deutsch (Paramètres › Langue).
  • Favoris et historique, enregistrés sur votre ordinateur.
  • Navigation privée : rien n'est enregistré, les cookies sont séparés.
  • Deux moteurs : WebKit pour les sites complets, Sanaga Léger pour lire vite avec très peu de mémoire.
  • Téléchargements vers votre dossier Téléchargements.
  • Recherche dans la page et zoom.

Bon à savoir

Le moteur WebKit affiche les sites comme un navigateur classique. Le moteur Sanaga Léger, lui, ne lance pas JavaScript : les messageries web, vidéos et applications en ligne y sont incomplètes, mais les sites d'information, encyclopédies et blogs s'y lisent très bien.

Pour commencer, essayez Wikipédia, Hacker News ou NPR en version texte.
